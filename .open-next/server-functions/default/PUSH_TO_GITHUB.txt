========================================
🚀 PUSH TO GITHUB - COPY & PASTE
========================================

STEP 1: Create GitHub Repository
---------------------------------
Open in browser: https://github.com/new

Settings:
- Repository name: dapumindai
- Visibility: Public
- DO NOT initialize with README
- Click "Create repository"


STEP 2: Copy These Commands
---------------------------------
After creating repository, GitHub will show you commands.

Copy the URL that looks like:
https://github.com/YOUR_USERNAME/dapumindai.git

Replace YOUR_USERNAME with your actual GitHub username!


STEP 3: Run in PowerShell
---------------------------------
(Make sure you're in the project folder)

# Add remote (REPLACE YOUR_USERNAME!)
git remote add origin https://github.com/YOUR_USERNAME/dapumindai.git

# Push to GitHub
git branch -M main
git push -u origin main


EXAMPLE:
---------------------------------
If your GitHub username is "johndoe":

git remote add origin https://github.com/johndoe/dapumindai.git
git branch -M main
git push -u origin main


AUTHENTICATION:
---------------------------------
When prompted for password, use:
- Personal Access Token (not your GitHub password)
- Get token: https://github.com/settings/tokens
- Click "Generate new token (classic)"
- Select scope: repo
- Copy token and use as password


STEP 4: Connect Cloudflare
---------------------------------
After successful push:

1. Go to: https://dash.cloudflare.com/pages
2. Click: "dapumindai" project
3. Click: "Settings" tab
4. Find: "Builds & deployments"
5. Click: "Connect to Git"
6. Select: GitHub
7. Choose: your "dapumindai" repository
8. Configure:
   - Build command: npm run build
   - Build output: .next
9. Click: "Save and Deploy"


DONE! 🎉
---------------------------------
Your site will be live in ~3 minutes at:
https://dapumindai.pages.dev
